# Vision

## Mission

Build a modern engineering portfolio that demonstrates not only technical ability, but engineering judgment, architecture, craftsmanship, and communication.

This project is intentionally built as though it were a production application.

---

## Audience

- Hiring Managers
- Software Engineers
- Technical Leads
- Architects
- Recruiters

---

## Goals

- Demonstrate modern Angular development
- Demonstrate enterprise Java architecture
- Showcase AWS deployment
- Practice clean architecture
- Showcase testing strategy
- Document engineering decisions

---

## Design Principles

Professional first.

Creative second.

Accessible always.

Performance matters.

Every feature should exist for a reason.

---

## Success

A visitor should leave thinking:

"This engineer cares about quality."

Not

"This engineer knows Angular."
